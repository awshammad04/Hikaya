# Hikaya MVP Plan

## Goal

The goal of the MVP is to demonstrate the main idea of Hikaya using a small number of selected Palestinian locations.

## MVP Scope

The first version will include:

1. Interactive map
2. 3–5 selected Palestinian locations
3. Location page for each place
4. AI-generated simplified story
5. Multimedia content support
6. User contribution form
7. Basic content review process

## Out of Scope for MVP

The following features will not be implemented in the first version:

- Full national heritage database
- Mobile application
- Advanced AR features
- Complex AI models trained from scratch
- Support for all Palestinian cities and villages

## Main User Flow

1. User opens Hikaya platform.
2. User explores locations on the map.
3. User selects a location.
4. System displays historical and cultural content.
5. AI generates a simplified story based on reviewed content.
6. User can read, listen, or submit a personal story.
